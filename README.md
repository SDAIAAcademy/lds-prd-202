# تقييم منتجات الذكاء الاصطناعي وتجاربها واقتصادياتها

Evaluation, Experiments and Economics for AI Products

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-PRD-202 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يتولى المشاركون مسؤولية الأدلة الخاصة بمساعد ذكاء اصطناعي في مرحلة المشروع التجريبي. فاستنادًا إلى 300 أثر تنفيذ (trace) اصطناعي، وسجل تجربة من 20,000 جلسة، وثلاث قوائم أسعار، يصنّفون أنماط الفشل، ويحولونها إلى مجموعة تقييم ذات إصدارات فيها مصححات وعتبات، ويخططون لتجربة مباشرة ويقرؤون نتائجها، وينمذجون التكلفة لكل مهمة ناجحة مقابل الجودة وزمن الاستجابة، وينتهون بتوصية إطلاق يناقشونها. ويبني المقرر DEV-EVL-301 إطار التقييم؛ أما هذا المقرر فيدرّب مالكه.

**الصيغة:** دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-prd-202/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يشرح لماذا تحتاج المخرجات المتغيرة إلى محاولات متكررة ومعايير ثنائية النتيجة ومصححات جرى التحقق من صحتها، استنادًا إلى أربعة ادعاءات دقة على غرار ادعاءات الموردين | Awareness | نقد يسمّي ما يغفله كل ادعاء |
| LO2 | يحلل آثار التنفيذ إلى تصنيف لأنماط الفشل مع تكرار كل نمط وشدته، استنادًا إلى 100 أثر من آثار المشروع التجريبي، تُوسَم مع ميسِّر يؤدي دور قائد الفريق الهندسي | Applied | خمسة أنماط فشل أو أكثر، لكل منها تعريف ومعرّفات آثار تنفيذ نموذجية وعدد مرات الظهور |
| LO3 | يعدّ مجموعة تقييم ذات إصدارات تسند إلى كل معيار فحصًا برمجيًا أو مصحِّحًا نموذجيًا أو مراجعة بشرية، وعتبة للإطلاق، استنادًا إلى تصنيف أنماط الفشل ومعايير القبول وتقرير معايرة للمصححات | Applied | مجموعة من 120 مثالًا مع اختيارات المصححات والعتبات وسجل للتغييرات |
| LO4 | يحلل تجربة مباشرة وفق مقاييس أساسية ومقاييس حماية ومقاييس تكلفة محددة مسبقًا، على سجل اصطناعي لتجربة بذراعين يضم 20,000 جلسة | Applied | خطة مسجلة مسبقًا وتقرير نتائج فيه فترات الثقة والقرار الذي تدعمه |
| LO5 | يحسب التكلفة لكل مهمة ناجحة ومئينات زمن الاستجابة لتهيئات بديلة للنموذج، باستخدام نسب الاجتياز وأعداد الوحدات النصية (tokens) والتوقيتات وثلاث قوائم أسعار | Applied | جدول لاقتصاديات الوحدة يبين الحساسية لحجم الاستخدام ونسبة النجاح والسعر |
| LO6 | يقرر الإطلاق أو مواصلة التحسين أو الإيقاف بالموازنة بين الجودة والتكلفة وزمن الاستجابة والمخاطر، استنادًا إلى جميع أدلة المقرر وضمن ميزانية ومستوى خدمة محددين | Performance | مذكرة إطلاق من صفحتين تُناقَش مباشرة |

## الأدوات

كل سطر قدرة، والأمثلة قابلة للتبديل.

- **عارض آثار التنفيذ:** Langfuse, Arize Phoenix, التتبع في MLflow
